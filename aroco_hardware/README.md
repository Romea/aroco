# aroco_hardware

## 1) Overview

`aroco_hardware` provides the live `ros2_control` hardware plugin for the Aroco mobile base.

It specializes the generic `2AS4WD` hardware abstraction from `romea_mobile_base_hardware` and connects it to the Aroco low-level controller through SocketCAN.

The exported plugin is:

| Plugin | Base class | Mobile base architecture |
|---|---|---|
| `aroco_hardware/ArocoHardware` | `HardwareSystemInterface2AS4WD` | `2AS4WD` |

## 2) Hardware concept

`ArocoHardware` is loaded by `controller_manager` from the `<ros2_control>` description generated by `aroco_description`.

At runtime, it:

1. reads the Aroco `ros2_control` hardware information;
2. creates the `HardwareInterface2AS4WD` command and state interface mapping;
3. loads front and rear wheel radii used to convert wheel angular speeds;
4. opens the Aroco CAN communication on `can0`;
5. starts a CAN listening thread for Aroco feedback frames;
6. converts controller-side wheel angular speed commands into Aroco wheel linear speed commands;
7. sends front and rear wheel speed commands and front and rear axle steering commands;
8. converts received wheel speed and steering feedback into `ros2_control` state interfaces;
9. sends null commands when the interface is connected or disconnected.

From the controller point of view, this behaves like a standard mobile base hardware plugin: `romea_mobile_base_controllers/MobileBaseController2AS4WD` writes front and rear axle steering commands and four wheel speed commands, then reads steering and wheel speed feedback from state interfaces to compute odometry.

## 3) CAN communication

The current implementation uses SocketCAN on:

```text
can0
```

The hardware plugin sends:

* an autonomous-mode start frame;
* front wheel linear speed commands;
* rear wheel linear speed commands;
* front axle steering angle commands;
* rear axle steering angle commands;
* null commands when the interface is connected or disconnected.

It receives:

* front wheel linear speed feedback;
* rear wheel linear speed feedback;
* front and rear axle steering angle feedback.

Wheel speeds are exchanged with the Aroco low-level controller as linear speeds on the CAN bus and exposed to `ros2_control` as wheel angular speeds.

## 4) Relation with other packages

`aroco_hardware` is the live hardware specialization of the Aroco mobile base:

* `aroco_description` selects `aroco_hardware/ArocoHardware` in `live` mode;
* `romea_mobile_base_hardware` provides the reusable `2AS4WD` hardware abstraction;
* `romea_mobile_base_utils` provides helpers used to read `hardware_interface::HardwareInfo`;
* `romea_mobile_base_controllers` sends commands through the exported `ros2_control` interfaces;
* `aroco_bringup` starts the controller manager and loads this hardware plugin in live mode.
